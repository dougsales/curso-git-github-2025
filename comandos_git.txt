git init .           -> cria um repositório git na pasta atual.
git status           -> mostra o status do trabalho (de cada arquivo).
git add nome_arquivo -> adiciona arquivo para ser comitado.
git commit -m "msg"  -> faz commit do que estava para ser comitado.
git log              -> mostra todo o historico de commits.

## FLUXO DE TRABALHO

1. Criar o diretório do projeto
2. Iniciar o git detro do diretório criado (git init .)
3. edita ou cria arquivos
4. git status
5. git add <nome arquivo>
6. git status
7. git commit -m "mensagem"
8. git status
9. volta ao passo 3.
